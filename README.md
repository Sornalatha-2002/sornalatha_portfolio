# Sornalatha S – Portfolio
1. Copy your resume to `public/resume/Sornalatha_S_Resume.pdf`
2. Add your LinkedIn and GitHub URLs to `profile.linkedin` / `profile.github` in `src/data/portfolio.js` (they stay hidden until set)
3. `npm install` then `npm run dev`
4. `npm run build` (output in `dist/`)
5. Deploy `dist/` to Netlify, Vercel, or GitHub Pages (build command `npm run build`, publish dir `dist`)

All site content lives in `src/data/portfolio.js`; sections are in `src/sections/`, styles in `src/styles/index.css`.
